Bootstrap 5.3.8.

## Способ подключения

Bootstrap подключён через CDN jsDelivr.

CSS подключается в `head`, следом за ним подключается собственный файл `css/custom.css`:

```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
<link rel="stylesheet" href="css/custom.css">
```

JS Bundle подключается перед закрывающим `</body>`. Он нужен для меню-гамбургера, модальных окон, карусели, вкладок, аккордеона и offcanvas:

```html
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
```

## Bootstrap-сетка

- `container`, `row`, `col-12`, `col-sm-*`, `col-md-*`, `col-lg-*`.
- `row-cols-*`: сетка карточек 1 → 2 → 3 колонки в зависимости от ширины экрана.
- Отступы между колонками: `g-2`, `g-3`, `g-4`, `g-5`.

## Реализованные компоненты

Обязательные:

- `navbar`: на всех страницах, сворачивается в меню-гамбургер на узких экранах;
- `card`: карточки товаров, отзывов, форм;
- `btn`: варианты `btn-primary`, `btn-outline-primary`, `btn-outline-secondary`, `btn-light`, размеры `btn-sm`, `btn-lg`;
- `badge`: «Хит», «Новинка», «−20%», «Нет в наличии», категории;
- `alert`: `alert-success`, `alert-info`, `alert-warning`;
- `modal`: «Заказать звонок» на всех страницах, «Купить в 1 клик» на странице товара;
- `form-control`, `form-select`, `input-group`, `form-check`;
- `accordion`: FAQ на главной.

Дополнительные:

- `carousel` в hero-блоке;
- `nav-tabs`: вкладки на странице товара;
- `pagination` в каталоге;
- `offcanvas-lg`: фильтры каталога, которые на телефоне выезжают сбоку;
- `breadcrumb`, `list-group`, `table`, `form-switch`.

## Самостоятельные доработки

1. **Дополнительные страницы.**
   - `contacts.html`: контакты в `list-group`, схема проезда на CSS, форма обратной связи.
   - `thanks.html`: страница после отправки любой формы. Сценарий заявки доведён до конца.
2. **Дополнительные Bootstrap-компоненты:** `carousel`, `tabs`, `pagination`, `offcanvas`, `breadcrumb`, `list-group`, `form-switch`.
3. **Улучшенный каталог:**
   - фильтры: поиск, категория, освещение, цена, «только в наличии»;
   - сортировка;
   - метки товаров;
   - карточка «нет в наличии» с кнопкой «Под заказ»;
   - пагинация.
4. **Улучшенный сценарий заказа:**
   - выбор комплектации и количества на странице товара;
   - быстрый заказ в модальном окне;
   - блок «Ваш заказ» с итоговой суммой;
   - выбор способа получения.
5. **Единый фирменный стиль через `custom.css`:**
   - цвета Bootstrap переопределены через CSS-переменные, без переписывания компонентов;
   - карточки поднимаются при наведении;
   - видимый фокус.
6. **Адаптивность:**
   - сетка карточек перестраивается от 1 до 3 колонок;
   - меню сворачивается в гамбургер;
   - фильтры на телефоне открываются в offcanvas.
7. **Доступность:** `aria-label`, `aria-current`, `visually-hidden`, подписи у всех полей.

## Как проверить проект

1. Открыть ссылку GitHub Pages или файл `index.html` в браузере. Нужен интернет, потому что Bootstrap загружается с CDN.
2. Сузить окно или открыть DevTools в режиме телефона: меню сворачивается в гамбургер, карточки перестраиваются в одну колонку, в каталоге появляется кнопка «Фильтры».
3. Проверить интерактивные компоненты:
   - нажать «Заказать звонок» в меню — откроется модальное окно;
   - на главной — карусель и аккордеон;
   - на странице товара — вкладки и кнопка «Купить в 1 клик».
4. Отправить любую форму. Пустые обязательные поля не пропустят отправку, после заполнения откроется страница «Заявка принята».
